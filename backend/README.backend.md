## Kloth: Backend

### This Directory
> This directory is used in the backend of Kloth. Some files may be ignored, check the root of the repository's .gitignore. The directory includes a series of sub-directories.
```
/backend/ ( current directory )
    src/
    tests/
```

> ``/src`` contains files for the code before it's been built. You can build it using ``npm run build``. ``/tests/`` includes a series of tests used by **vitest**. Tests can be ran using ``npm run test:run``.
