## Kloth

### What is Kloth?
> Kloth is an open-source messaging service with E2EE (end-to-end encryption), providing privacy, security and freedom in your communications. Supporting multiple features such as permissions, direct messages, huddles, communities, sections, spaces and **so much more**.

### What is E2EE and how does it make your communications private?
> E2EE (or end-to-end encryption) is a protocol where a set of codes are exchanged between message participants. These set of codes are known as private keys, and are not shared with any backend servers, only the people you're communicating with. This means that nobody apart from participants can read your messages, they're all encrypted! This includes images, videos, emojis and so much more!

### Project in Development!
